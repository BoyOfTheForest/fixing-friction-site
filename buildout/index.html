Buildout: design levers

Internal page. It is not in the menu or the sitemap, and search engines are told to skip it. Nothing here is secret: the site code is public on GitHub. Each lever is a design change that can be undone and redone without losing the other version.

How the old design is kept

  • Git tags. before-levers is the whole site before any lever. lever-01 to lever-05 mark each change, so each one can be reverted on its own.
  • A live copy of the old design at /buildout/archive/before-levers/. Open it next to the live site to compare. It is hidden from search engines.
  • Patch files for every lever in /buildout/archive/patches/.

How to use a prompt

Press the copy button, paste the prompt into Claude Code opened in the site folder, and send it. The prompt works on a new branch, checks every page, and waits for your OK before anything goes live.

Now: robots.txt blocks all crawlers, so search engines and AI answer engines stay out until the build is reviewed and approved. The old allow-all file is saved at /buildout/archive/robots.allow.txt. Note that blocking stops crawling, but a page that was already indexed can linger in results for a while.
